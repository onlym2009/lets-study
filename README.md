# تطبيق المذاكرة (Study App)

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose + Room) — بدون إنترنت، كل حاجة متخزنة محلي على الجهاز.

## المميزات
- **المواد**: تضيف مادة، تدوس عليها، تدخل جوّاها.
- **محاضرات جوه كل مادة**: زرار + يضيف "محاضرة" باسم تختاره.
- **مرفقات جوه كل محاضرة**: صور، PDF، وملفات صوتية — بتتنسخ لتخزين التطبيق الداخلي عشان تفضل موجودة حتى من غير نت وحتى لو مسحت الملف الأصلي.
- **جدول المذاكرة**: مواعيد مذاكرة بتاريخ ووقت، ممكن تربطها بمادة.
- **جدول المحاضرات والمواعيد**: نفس الفكرة لكن لمحاضرات فعلية أو مواعيد عامة.

## إزاي تبني الـ APK من الموبايل (من غير كمبيوتر) — GitHub Actions
1. من متصفح موبايلك، ادخل github.com وسجل دخول.
2. اعمل **New repository** (اسم مثلا `lets-study`)، خليه Public، من غير أي ملفات ابتدائية.
3. من صفحة الريبو، دوس **Add file → Upload files**، وارفع كل ملفات ومجلدات المشروع ده (لازم تفك الضغط عن الملف الأول وترفع المحتوى بنفس الشكل: `app/`, `.github/`, `build.gradle.kts`, `settings.gradle.kts`).
   - لو المتصفح مش بيسيبك ترفع فولدرات كاملة بسهولة، جرب تطبيق زي **GitHub Mobile** أو متصفح Chrome لسطح المكتب (Desktop site) عشان اختيار الفولدر يبقى متاح.
4. بعد الرفع، اضغط **Commit changes**.
5. روح تاب **Actions** فوق في الريبو — هتلاقي "Build APK" شغال أو خلص تلقائيًا (بياخد كام دقيقة).
6. لما يخلص (علامة صح خضرا)، ادخل عليه، ولاقي في الآخر **Artifacts → LetsStudy-debug-apk** — دوس عليها تنزل ملف zip فيه الـ APK.
7. فك ضغط الملف على موبايلك ودوس على `app-debug.apk` عشان تنصبه (ممكن يطلب منك تفعيل "تثبيت من مصادر غير معروفة" من إعدادات الأمان).

## إزاي تشغّله من كمبيوتر (لو حبّيت لاحقًا) — خطوات
1. افتح **Android Studio** (أحدث نسخة).
2. اختار **Open** وافتح فولدر `StudyApp` ده كامل كمشروع (فيه build.gradle.kts, settings.gradle.kts جاهزين).
3. سيب Android Studio يعمل Gradle Sync (أول مرة هياخد وقت وهيحمل الـ Gradle wrapper والمكتبات — محتاج نت للخطوة دي بس).
4. لو طلب منك يعمل Upgrade لـ AGP/Gradle وقت الـ Sync، وافق عادي.
5. وصّل موبايل أندرويد (USB + Developer Options + USB Debugging) أو شغّل Emulator.
6. دوس **Run ▶️** — هيتثبت التطبيق مباشرة.
7. لو عايز ملف APK تنصبه يدوي: من قايمة **Build → Build App Bundle(s) / APK(s) → Build APK(s)**، وهتلاقي الملف في:
   `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات
- الحد الأدنى لنسخة أندرويد المدعومة: Android 7.0 (API 24).
- مفيش أي صلاحيات تخزين مطلوبة — بيستخدم منتقي الملفات (File Picker) بتاع النظام، وده أأمن وأحدث طريقة.
- لو عايز تضيف تنبيهات (Notifications) قبل ميعاد المحاضرة/المذاكرة بوقت معين، ده تحسين سهل أضيفه بعدين (WorkManager/AlarmManager).
